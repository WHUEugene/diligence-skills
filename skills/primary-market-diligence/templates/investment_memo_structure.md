# 一级市场投资研究报告模板

## 一、研究范围与项目概况

1. 项目背景与委托目的
2. 目标公司/项目基本情况
3. 交易目的和研究范围
4. 报告核心判断

## 二、行业情况

1. 行业定义与边界
2. 产业链结构
3. 市场规模、增长驱动和周期
4. 技术路线、产品路线和商业模式
5. 竞争格局与代表公司
6. 成本结构、资本开支和关键瓶颈
7. 政策、监管和行业风险
8. 对本项目的启示

## 三、公司业务情况

1. 公司基本情况和股权结构
2. 拟发展新方向/新项目边界
3. 产品、服务和收入结构
4. 技术、研发、知识产权和量产状态
5. 客户、订单、渠道和销售模式
6. 供应链、生产交付、设备和产能
7. 财务预测、资金需求和资金用途
8. 尚未补齐的关键资料

## 四、公司在行业环境中的优劣势

1. 与行业机会的匹配度
2. 产品和技术优势
3. 客户、渠道和资源优势
4. 成本、产能和供应链优势
5. 团队、治理和执行能力
6. 短板、未验证假设和注意点
7. 可比公司/竞品对标结论

## 五、投资方案

1. 投资逻辑
2. 建议投资方式
3. 估值判断和依据
4. 投资金额、股权比例和出资节奏
5. 资金用途和里程碑
6. 退出路径
7. 基准、乐观、压力情景

## 六、风控措施

1. 投前先决条件
2. 分期出资和里程碑
3. 治理权和重大事项否决权
4. 信息权、审计权和投后监控
5. 回购、补偿、估值调整或违约责任
6. 资金监管和用途限制
7. 否决项和需人工核验事项

## 七、结论

- 建议：投资 / 附条件推进 / 暂缓 / 不建议
- 核心理由
- 必须补充资料
- 核心风控条件
- 人工核验事项

## 八、资料来源与待核验事项

1. 公开资料来源
2. 公司内部资料来源
3. 证据等级说明
4. 待核验事项清单
5. 工作限制

不得在报告开头设置“重要提示”“重要声明”“报告边界”“使用说明”或“附录”章节；资料来源和待核验事项统一放在最后。
