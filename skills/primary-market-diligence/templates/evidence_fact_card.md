# 证据与事实卡片模板

| 字段 | 内容 |
|---|---|
| source_id | PUB-001 / INT-001 / EXP-001 |
| source_name | 文件、网页、访谈或公告名称 |
| source_type | 招股书、年报、公告、政策、研报、官网、专利、内部资料、访谈、合同、检测报告等 |
| publish_or_provided_date | 发布时间或提供日期 |
| url_or_path | 链接或本地路径 |
| provider | 提供方或访谈对象 |
| confidentiality | public / internal / confidential |
| evidence_level | S / A / B / C / D |
| fact | 可回溯事实 |
| data | 数字、单位、时间范围、口径 |
| claim_supported | 支撑或反驳的 BP/公司主张 |
| module | 行业 / 公司业务 / 优劣势 / 投资方案 / 风控 |
| caveat | 适用范围、冲突数据、缺口 |
