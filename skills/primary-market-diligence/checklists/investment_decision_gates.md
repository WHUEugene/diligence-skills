# 投资决策闸门

## 1. 投前必须回答

| 问题 | 最低证据要求 | 未满足处理 |
|---|---|---|
| 行业是否真实存在投资机会 | 公开来源和可比公司 baseline | 暂不进入估值 |
| 公司新项目边界是否清楚 | 产品清单、一期/远期规划 | 要求补资料 |
| 技术是否能量产 | 检测、中试、良率、客户验证 | 专家核验或暂缓 |
| 收入是否有客户支撑 | 客户、送样、认证、合同/意向 | 降低估值或设前置条件 |
| 毛利率和成本是否合理 | 成本模型、同行对标、设备折旧 | 压力测试 |
| 资金是否能到位 | 自有资金、银行授信、担保 | 分期出资或暂缓 |
| 治理权是否保护投资方 | 章程、股东协议、重大事项权利 | 条款重谈 |
| 退出是否可行 | 回购、并购、IPO、转让路径 | 降低投资强度或不投 |

## 2. 风控条款检查

- 投前先决条件是否明确。
- 分期出资是否绑定可验证里程碑。
- 是否有重大事项否决权。
- 是否有信息权、审计权和现场核验权。
- 是否有资金监管和用途限制。
- 是否有回购、补偿、估值调整或违约责任。
- 关联交易是否有定价机制和审计权。
- 政策补贴、贷款、土地等外部支持是否有兑现条件和失败处理。

## 3. 结论表达

只能使用四类结论：

- 建议投资。
- 附条件推进。
- 暂缓，待补充资料。
- 不建议投资。

不得在重大证据缺失时写成无条件建议投资。
