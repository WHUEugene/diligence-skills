# 公开资料质量检查

在引用公开资料形成行业结论前，逐项检查：

| 检查项 | 通过标准 |
|---|---|
| 来源可回溯 | 有 URL、文件路径、发布日期或披露主体 |
| 口径清楚 | 明确全球/中国、收入/产值/销量、年度/季度、材料/产品/下游 |
| 来源可信 | 优先官方、监管披露、招股书、年报、公告、协会、标准 |
| 数据未孤证 | 关键数字尽量有两个以上来源或与可比公司披露相互印证 |
| 观点降级 | 媒体/研报观点不直接作为事实，需标注为观点 |
| 与项目相关 | 说明该事实如何影响目标项目，而不是只证明行业热门 |
| 冲突处理 | 冲突数据并列说明，不强行平均 |
| 时间有效 | 标注数据截止时间，避免旧数据支撑当前判断 |

不通过的资料只能作为线索，不能支撑投资结论。
