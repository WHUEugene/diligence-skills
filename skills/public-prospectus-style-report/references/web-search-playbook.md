# Web Search Playbook

## Evidence Grades

Use current web search only when local materials are insufficient or the user
asks for current information. Grade sources before using them:

| Grade | Source type | Use |
|---|---|---|
| A | Exchange, CNINFO, CSRC, government, company announcement | Can support factual statements. |
| B | Company official website, patent, standard, environmental filing, tender | Can support company/project context with caveats. |
| C | Industry association, securities research, reputable media | Use for market context, not definitive target facts. |
| D | Third-party mirrors, marketing posts, self-media | Discovery only unless cross-verified. |

## Search Buckets

Run searches by bucket instead of mixing everything:

1. **Issuer/prospectus**: company name, ticker, prospectus, annual report,
   fundraising projects.
2. **Industry policy**: regulator, industry plan, standards, statistical
   bulletins.
3. **Project trace**: target/project/company name plus city, park, filing,
   environmental assessment, construction start, investment agreement.
4. **Technology**: material keyword, performance indicator, patent, standard,
   customer validation.
5. **Customers and competitors**: downstream customer names, certification,
   order, supplier qualification, comparable companies.

## Use Rules

- Do not cite media claims when an official filing exists.
- Do not use market-size numbers without source date, scope, and definition.
- Separate search snippets from verified source content.
- Save URLs in the source registry even if the source is used only as a clue.
- If a webpage is unstable, save a snapshot path and record the access date.
