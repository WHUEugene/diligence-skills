# Four-Module To Prospectus Map

Use the leader's four modules as the report structure. Use prospectuses only to
borrow writing style, evidence order, and disclosure discipline.

| Leader module | Prospectus chapters to reference | Required output |
|---|---|---|
| 行业情况 | `业务与技术`中的`发行人所处行业基本情况及其竞争情况`; `风险因素`中的行业风险 | 行业定义、产业链、下游需求、竞争格局、行业风险 |
| 项目业务情况 | `业务与技术`中的主营业务、主要产品、工艺流程、核心技术、客户供应商; `募集资金运用`; `财务会计信息与管理层分析` | 项目基本情况、产品方案、技术工艺、投资规模、财务预测 |
| 项目在行业环境中的优劣势 | `业务与技术`中的竞争地位、竞争优势、核心竞争力; `风险因素`中的技术、市场、客户、原材料、毛利率、募投风险 | 潜在优势、主要短板、可比公司对标 |
| 投资方案与风控措施 | `募集资金运用`中的项目必要性、可行性、建设内容、产能消化; `风险因素`中的风险揭示 | 投资判断、分期出资、先决条件、交易条款、否决项 |

Do not generate standalone IPO chapters such as `释义`, `概览`,
`发行人基本情况`, `公司治理`, `投资者保护`, `有关声明`, or `备查文件` unless
the user explicitly asks for a full prospectus simulation.

The final `资料来源与待核验事项` section is evidence plumbing, not a fifth
business module.
